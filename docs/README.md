# Documentation Index

This folder is now organized around the core areas of the application. Use the table
below to find the right reference quickly.

- **architecture/** – System-level references (backend, frontend, service-detection).
- **features/** – Per-feature deep dives (notifications, schedules, assets, scans, UI).
- **operations/** – Runbooks, integration notes, and test checklists.
- **practices/** – Engineering playbooks and best-practice collections.
- **initiatives/** – Reserved for in-flight program documents.
- **archive/** – Historical context and legacy review notes.

Each subdirectory includes README files where necessary; add new material in the
appropriate section to keep the structure consistent.
